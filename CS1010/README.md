# CS1010 PE preparation guide

`CS1010_PE_Prep_Guide_EN.docx` is an English, concept-first Word guide for progressive PE preparation. It focuses on reasoning patterns, implementation checks, and small C17 examples rather than reproducing every item from the original PDF.

The example programs were compiled with strict C17 warnings and UndefinedBehaviorSanitizer during the closing review. This is an unofficial study aid; confirm the current semester's permitted language subset and assessment rules against official course materials.
